💜 Nora — Assistente digital acessível | Projeto de desenvolvimento de software
Desenvolvimento e programação: Sarah Belchior

Estou desenvolvendo a Nora, uma aplicação para ajudar na organização de rotinas, compromissos e tarefas, com recursos de acessibilidade, apoio por inteligência artificial e bem-estar. O projeto possui interface web para computador e celular e um protótipo Android.

Minha atuação no desenvolvimento:
- Programação, configuração e evolução de funcionalidades da aplicação web, trabalhando com Python/FastAPI, JavaScript, HTML, CSS e SQLite;
- integração e configuração de APIs, incluindo serviços de IA, e cuidados com credenciais no servidor;
- trabalho com persistência de dados, estrutura frontend/backend, sessões e rotinas de backup;
- desenvolvimento e testes da experiência mobile, com Android Studio, Gradle e emulador Android;
- investigação e correção de erros reais de execução, validação e comunicação entre aplicativo e servidor;
- planejamento de recursos de acessibilidade, navegação, organização pessoal e Nora Sleep, além de testes e aprimoramentos contínuos.
Tecnologias do projeto: Python FastAPI SQLite JavaScript HTML CSS REST APIs Android Studio Java/WebView

Situação: protótipo em desenvolvimento e testes. O Android ainda não é uma versão publicada em loja; funcionalidades de saúde não são sistemas clínicos validados.

📊 Pesquisa científica — TEA no Ceará (2020–2025)
Sou autora da proposta de pesquisa “Análise epidemiológica dos registros relacionados ao Transtorno do Espectro Autista (TEA) no estado do Ceará: estudo do período de 2020 a 2025”, apresentada ao INBEC.

O estudo utiliza documentos e fontes públicas do IBGE, DATASUS/SUS e da Secretaria da Saúde do Ceará, discutindo os indicadores populacionais e os limites dos registros assistenciais. A análise anual detalhada das séries históricas está prevista como etapa de investigação.

🔗 [Conhecer a pesquisa](https://github.com/sarahbelchior/pesquisa-tea-ceara)
